<h1> Amigo Secreto  😎😶‍🌫️ </h1>

- Estado del proyecto: Finalizado.

<h1> Descripción </h1>

Actividad popular donde un grupo de personas se intercambian regalos de forma anónima. Para organizarlo, cada participante saca el nombre de otro para darle un regalo, pero sin saber quién le dará un regalo a él.
